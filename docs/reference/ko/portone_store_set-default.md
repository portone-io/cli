# portone store set-default

[English](../portone_store_set-default.md) | 한국어

설정 프로필의 기본 상점 지정

```
portone store set-default [OPTIONS] [ID]
```

## 인자

| 인자 | 설명 |
| --- | --- |
| `<ID>` | 기본값으로 저장할 상점 ID |

## 옵션

| 옵션 | 설명 |
| --- | --- |
| `--profile <NAME>` | 사용할 설정 프로필 |
| `--view` | 저장된 기본 상점 ID 출력 |
| `--unset` | 저장된 기본 상점 설정 해제 |
