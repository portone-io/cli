# portone setup

[English](../portone_setup.md) | 한국어

AI 코딩 에이전트용 PortOne 스킬과 MCP 설정 설치

```
portone setup [OPTIONS] [COMMAND]
```

## 명령어

| 명령어 | 설명 |
| --- | --- |
| [portone setup update](portone_setup_update.md) | 기록된 PortOne 스킬과 MCP 설정 업데이트 |

## 옵션

| 옵션 | 설명 |
| --- | --- |
| `--agent <AGENT>` | 설정할 에이전트 (쉼표로 구분하거나 여러 번 지정) [가능한 값: claude-code, codex, cursor, gemini-cli, github-copilot, vscode-copilot, opencode] |
| `--scope <SCOPE>` | 설치 범위 (project \| user) [가능한 값: project, user] |
